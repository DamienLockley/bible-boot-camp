BIBLE BOOT CAMP — COMPLETE OFFLINE PWA

This package includes all 28 extracted studies, 17 original embedded illustrations, and 31,102 KJV verses. No Google Apps Script banner. Your existing Google Apps Script app is unchanged.

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP. Open the BibleBootCamp_Offline_PWA folder.
2. Create a public repository on github.com, e.g. bible-boot-camp.
3. Upload ALL files and the assets folder from INSIDE BibleBootCamp_Offline_PWA into the repository root (not the outer folder). GitHub's browser upload supports dragging files and folders; verify that index.html is at repository root and assets is a folder.
4. Open Settings > Pages. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
5. Once published, visit the HTTPS Pages URL while online and wait for the studies to load. Wait until the offline download is complete before disconnecting.
6. iPhone: open the URL in Safari > Share > Add to Home Screen. Android: Chrome > Install app or Add to Home screen.
7. Open the installed app while online, then test by enabling airplane mode, closing and reopening it.

NOTE: Offline files are cached during the first online visit by a service worker; the app needs HTTPS or localhost. A local file:// double-click cannot test offline caching. Updates require a new service-worker CACHE version and an online visit. Browser storage can be cleared by the user or device, requiring a fresh download.

The studies are an automatic conversion of the original Word document. Some unusual scripture references may not resolve; the original study content has not been rewritten.
