GTKJ ENGLISH DESKTOP REVIEW - MAIN POINTS AND ANALOGIES
====================================================

This is the separate review branch, not your live website.
No changes have been published to the public main branch.

OPTION A - YOUR SITE MANAGER
1. Download this branch as ZIP and extract it.
2. Add this extracted folder as a SEPARATE local preview site in your Site Manager.
3. Make index.html the site root and run the site's local-host preview.
4. Do not use the Site Manager's Publish/Commit-to-main action with this review folder.
5. Browse any of the 28 studies. Scroll to the end of each to review:
   - MAIN POINTS - REVIEW DRAFT (central principle, 3 core ideas, 6 teaching steps)
   - PROPOSED ANALOGY - REVIEW DRAFT.

OPTION B - WINDOWS LOCALHOST
Double click START_DESKTOP_REVIEW.bat from the extracted folder.
This requires Python installed and opens http://localhost:8765/.
You may instead use your existing localhost server.

IMPORTANT REVIEW SAFETY
- Local review notes and progress are kept in a SEPARATE browser storage key.
- All 28 studies are unlocked for your review.
- Firebase account login/synchronization and admin functions are disabled in the
  desktop review. Your production account is not accessed.
- Contact form submissions are disabled: no emails will be sent.
- Scripture popups need teachers-guide/kjv-verses.json in this extracted site;
  do not copy only index.html into an empty folder.
- Keep the full extracted folder structure, assets and scripts together.
- Online integrations are not tested by this local preview.
- Any later Word-to-site conversion could replace these draft changes.
- The public English and Tagalog sites remain unchanged.
