REVELATION — COMPLETE NARRATIVE STUDY PACKAGE

CONTENTS
1. Revelation_Complete_Narrative_Study.html — offline study site with 53 scenes, chapter explanations, 404 KJV verse slots, source links and scripture popups.
2. Revelation_Complete_Narrative_Master.docx — editable Word commentary with complete scene coverage, linked main readings and biblical references.

4. sources/ — all your supplied SSS, Light Bearers and Preludes of Hope PDF studies, Great Controversy PDF, SDA Commentary and supporting documents.

HOW TO GET AN EDITABLE WORD DOC WITH ALL 404 KJV VERSES INCLUDED
- Extract the entire ZIP, keeping the files and sources folder together.
- Open Revelation_Complete_Narrative_Study.html in a browser.
- Click 'Load KJV from GitHub', or select the kjv-verses.json file saved from your teachers-guide on GitHub.
- Click 'Export complete KJV Word (.docx)'. The resulting Word file contains every verse of Revelation in passage order, followed by the narrative and spiritual study.
- Move the exported Word file into the extracted Revelation_Final_Study folder if you want its relative links to source PDFs to open locally.
- That Word export is made directly from your KJV source at the time you click; the offline HTML without a JSON file has the KJV verse citations and all explanations, but not the verse bodies already embedded.
